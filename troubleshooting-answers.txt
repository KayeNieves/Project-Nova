CS223 Activity 5 - Git Mastery & Troubleshooting

1. Oops, wrong file
Solution: Unstage .env while preserving its working-tree changes.
Commands:
git restore --staged .env
(Alternative: git reset HEAD .env)

2. Typo in the commit message
Solution: Amend the most recent unpushed commit message.
Command:
git commit --amend -m "Fixed authentication typo"

3. Forgot a file
Solution: Add styles.css to the previous commit without changing its message.
Commands:
git add styles.css
git commit --amend --no-edit

4. I hate these changes
Solution: Discard uncommitted changes to index.html and restore its last committed version.
Command:
git restore index.html
(Alternative: git checkout -- index.html)

5. Wrong branch
Solution: Preserve the three unpushed commits on new-feature, then move main back three commits.
Commands:
git branch new-feature
git reset HEAD~3 --hard
git checkout new-feature

6. Detached HEAD
Solution: Create a branch at the current commit to preserve the new work.
Command:
git switch -c recovery-branch
(Alternative: git checkout -b recovery-branch)

7. Undo a pushed mistake
Solution: Reverse the buggy commit with a new commit without rewriting shared history.
Command:
git revert <buggy-commit-hash>

8. Accidental deletion
Solution: Recreate the deleted branch at its last known commit.
Command:
git branch <deleted-branch-name> <commit-hash>

9. Ghost files
Solution: Stage tracked file deletions made through the file explorer.
Command:
git add -u
(Alternative: git rm <filename>)

10. Pushed to the void
Solution: Delete the unwanted remote branch named testing-junk.
Command:
git push origin --delete testing-junk
