CS223 Activity 5 - Troubleshooting Answers

1. Wrong file staged: Unstage .env and keep its local changes.
git restore --staged .env

2. Commit message typo: Correct the latest unpushed commit message.
git commit --amend -m "Fixed authentication typo"

3. Forgot a file: Add styles.css to the previous commit without changing its message.
git add styles.css
git commit --amend --no-edit

4. Unwanted changes: Restore index.html to its last committed version.
git restore index.html

5. Wrong branch: Preserve the three unpushed commits on new-feature, then reset main.
git branch new-feature
git reset HEAD~3 --hard
git checkout new-feature

6. Detached HEAD: Create a branch at the current commit.
git switch -c recovery-branch

7. Undo a pushed mistake: Revert the buggy commit without rewriting shared history.
git revert <buggy-commit-hash>

8. Recover a deleted branch at its last known commit.
git branch <deleted-branch-name> <commit-hash>

9. Ghost files: Stage tracked file deletions.
git add -u

10. Delete the unwanted remote branch testing-junk.
git push origin --delete testing-junk
